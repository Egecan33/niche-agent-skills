# Release scope

The initial public repository is `Egecan33/niche-agent-skills`. Only this package's reviewed source, documentation, synthetic examples, tests, and license notices belong in it. The earlier eight general-purpose skill drafts remain outside this repository.

Original material uses MIT with the public handle Egecan33 for attribution. Upstream license notices remain separately attributed; no upstream implementation is shipped. Future copied/adapted material requires an exact-file review and provenance update first.

Public source availability does not imply a plugin catalog listing, host certification, or executed upstream integration. The README and validation record keep those limitations visible. This release needs no hooks, external-service credentials, customer data, dependency installation or changes to other repositories.
